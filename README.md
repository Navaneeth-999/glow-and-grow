# Glow & Grow Hair Care

A modern, responsive e-commerce & showcase web template for the botanical hair care brand **Glow & Grow**.

```text

│
├── index.html
│
├── css/

│
├── js/
│   └── script.js
│
├── assets/
│   ├── images/
│   │   ├── hero-hair.jpg
│   │   ├── shampoo.png
│   │   ├── conditioner.png
│   │   ├── serum.png
│   │   └── hair-model.jpg
│   │
│   └── icons/
│       ├── shine.svg
│       ├── smooth.svg
│       └── healthy.svg
│
└── README.md
```

## 🚀 Getting Started

1. Open `index.html` directly in any web browser (Double-click or right-click -> Open with Chrome / Edge / Firefox).
2. Alternatively, serve via a local HTTP server:
   ```bash
   python -m http.server 8000
   ```
   and navigate to `http://localhost:8000`.
